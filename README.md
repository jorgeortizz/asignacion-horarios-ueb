# Sistema de Asignación de Horarios Docente-Curso

Proyecto Núcleo 1 - Universidad El Bosque.

## Descripción

Sistema de información para apoyar la asignación
semestral de horarios académicos del Programa de
Ingeniería de Sistemas.

## Tecnologías previstas

- Java
- Spring Boot
- Spring MVC
- Spring Data JPA
- MySQL
- Maven
- Thymeleaf

## Organización

- backend/: aplicación Spring Boot.
- database/: scripts y diseño de base de datos.
- docs/: documentación académica y técnica.

## Estado del proyecto

Preparación del repositorio y entorno de desarrollo.

## Metodología

Enfoque híbrido SDLC y Scrum.
